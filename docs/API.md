# API 说明

所有响应为 JSON，邮件原文下载除外。错误格式为 `{ "error": "..." }`。管理接口须使用 `Authorization: Bearer <ADMIN_API_KEY>`，只能从服务端调用；客户接口使用 `HttpOnly` Cookie。

以下 `https://inbox.example.com` 是示例地址。时间一律使用带 `Z` 或 `+09:00` 等时区的 ISO 8601 字符串。服务端归一化为 UTC。

## 管理接口

### `POST /api/admin/mailboxes`

创建一个订单专属邮箱；同一 `externalId` 重试时返回已有邮箱，避免重复创建。只创建可收信地址，**此时没有客户密码**。

```json
{"externalId":"order-20261111-001","expiresAt":"2026-12-01T12:00:00+09:00"}
```

成功返回 `201`（首次）或 `200`（已存在），字段包括 `id`、`address`、`status`、`expiresAt`、`purgeAt`、`credentialsIssued`。`externalId` 限 1–128 位字母、数字、点、下划线、冒号和短横线。到期时间必须在未来 90 天内。

### `GET /api/admin/mailboxes/{id}`

查看状态和到期时间，不返回客户密码或摘要。

### `GET /api/admin/mailboxes/{id}/messages`

返回最多 50 条邮件元数据，用于排查收信；不返回正文。

### `GET /api/admin/mailboxes/{id}/code?since=2026-11-11T03%3A00%3A00Z`

从该邮箱中查找 `since` 之后、发件人为 `info@mail-pokemon-cafe.jp` 的最近验证码邮件，返回：

```json
{"code":"834921","messageId":"...","receivedAt":"2026-11-11T03:00:04.000Z"}
```

`since` 必须是最近 24 小时内的时间，推荐传本次提交预约信息前的时间。未找到时返回 `404`；调用方应短间隔重试到预约步骤超时，不要把 `404` 当作永久失败。

### `POST /api/admin/mailboxes/{id}/credentials`

预约成功、准备交付时调用。生成客户密码并**仅在本次响应中返回明文**：

```json
{"address":"mb-...@example.com","password":"一次性返回的随机密码","expiresAt":"..."}
```

服务端只保留带密钥的摘要。再次调用会重置密码并撤销已有会话；不要在重试逻辑中无意重复调用。交付系统应在同一事务流程中安全保存或立即展示这次响应，避免密码丢失后无法通知客户。不要把响应写入普通应用日志或飞书表格。

### `POST /api/admin/mailboxes/{id}/disable`

立即停用地址、撤销客户会话，并安排清理。重复调用结果仍为停用状态。已经下载、截图或转发的邮件无法收回。

## 客户接口

客户打开 `/` 或 `/login`，页面自动调用以下接口。客户不需要自己调用 API。

| 方法与路径 | 作用 |
|---|---|
| `POST /api/login` | 提交 `{ "address": "...", "password": "..." }`，设置 12 小时内且不超过邮箱到期时间的会话 Cookie |
| `GET /api/me` | 返回当前登录邮箱和到期时间 |
| `GET /api/messages` | 返回该邮箱最近 50 封邮件 |
| `GET /api/messages/{id}` | 返回发件人、收件人、主题、时间及安全文本内容 |
| `GET /api/messages/{id}/raw` | 下载该封实际收到的 `.eml` 原文 |
| `POST /api/logout` | 退出并撤销当前会话 |

客户不能查看其他邮箱的邮件；跨邮箱邮件 ID 返回 `404`。邮箱停用或到期后，上述读取接口返回 `401`。连续密码错误 5 次会锁定 15 分钟。

## 常见状态码

| 状态码 | 含义 |
|---|---|
| `400` | 参数错误，如时间无时区或订单 ID 格式不合要求 |
| `401` | 管理密钥错误、客户未登录或邮箱已到期 |
| `403` | 浏览器请求来源与当前站点不一致 |
| `404` | 邮箱/邮件不存在，或暂未找到验证码 |
| `409` | 对已停用或过期邮箱签发密码 |
| `429` | 客户密码多次错误，暂时锁定 |
| `503` | 资源未配置或存储暂时异常；检查 Worker 日志和绑定 |
